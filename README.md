# Grapheme — releases

Скачиваемые сборки и Sparkle-appcast для [Grapheme](https://github.com/itpnews/grapheme) — локальной голосовой диктовки для macOS.

Исходный код закрыт и лежит в другом (приватном) репозитории. Здесь — только бинарники и `appcast.xml`, которые нужны механизму автообновления (Sparkle) и для ручного скачивания.

Релизы подписаны Developer ID (`The Metaverse Apps OU`) и нотаризованы Apple.
